# Real-Time Project Collaboration App

A real-time project and task collaboration application built with React, Express, PostgreSQL, and Socket.IO.

## Features

- Project and task management
- Real-time updates with Socket.IO
- Authentication and member roles
- Comments, activity notifications, and file attachments

## Run the project

### Frontend

```bash
cd Frontend
npm install
npm run dev
```

### Backend

```bash
cd Backend
npm install
npm run dev
```

Create `.env` files in the `Frontend` and `Backend` directories before starting the application.
